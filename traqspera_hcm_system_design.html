Architectural pattern
Strangler-fig modular monolith. Laravel core stays for stable capabilities (time, paystubs, employee, direct deposit). New HR modules are clean .NET services extracted outside the monolith, connected over versioned Kafka topics and REST contracts. The PHP monolith shrinks as each module is extracted; it is never rewritten in place.

Architectural principles
🏛️ Clean architecture in every new service — dependencies point inward; domain has zero framework imports
📡 Event-driven by default for cross-service comms; synchronous calls only when latency demands it
🌿 Strangler-fig — every new capability built outside the monolith; monolith reduces over time, never rewritten in place
🗃️ One DB per service — no shared schemas; data exchanged via events or explicit APIs only
📋 Contracts before code — every Kafka topic and REST endpoint has a published, versioned schema before implementation
📱 Field-first — every HR capability ships mobile + web in the same release
🔒 Tenant isolation is non-negotiable and enforced at the data layer, not just request layer

Unique competitive moat — post-GR
Trimble-native ERP depth
Only HR platform with native Prism/Financials job-cost and payroll integration. No competitor can replicate without a Trimble partnership.
Field-first full stack
Mobile-first time → paystub → onboarding → benefits in a single app. Field workers don't need a separate tool for each workflow.
Construction-context AI
Time anomaly detection, certified payroll compliance, crew attrition forecasting trained on construction-domain data — not generic HR data.
AI architectural principles
📡 AI features consume the same Kafka event streams as the rest of the platform — no out-of-band data extraction
🔁 Inference is a service, not an embedded library — model swaps do not require service redeploys
🏢 Tenant data is never used to train cross-tenant models without explicit, contractual opt-in
📋 Every AI-assisted action is auditable: prompt, response, and downstream change recorded
🧑‍⚖️ Human-in-the-loop is the default for any action touching pay, benefits, or performance ratings
AI opportunity map — module by module
📋
Onboarding intelligence Beta
Document understanding (I-9, W-4, certifications) with field auto-fill. Risk scoring on missing or inconsistent paperwork before day one. ATS connector data enrichment for profile pre-population.
⏱️
Time & payroll anomaly detection Alpha+
Flags impossible shifts, duplicate punches, job-geofence drift before entries reach payroll. Supervisor review surface surfaces top anomalies ranked by risk. Estimated reduction: 60-80% of payroll correction cycles.
💊
Benefits personalization GR
Personalized plan recommendations surfaced at enrollment and life events. Natural-language Q&A grounded in carrier plan documents. Life-event prompts ("You've added a dependent — do you want to review coverage?").
🎯
Performance draft assist GR
Draft-assist for manager reviews and goal setting. Bias-checking on review language before submission. Topic clustering across check-ins to surface longitudinal themes for calibration panels.
📱
Field self-service — voice + NL Post-GR
Voice and natural-language interfaces in traqmobile for paystubs, PTO requests, and personal info — critical for low-literacy or ESL field users. Estimated ~40% of construction workforce benefits directly.
📊
Workforce insights Post-GR
Attrition risk scoring per crew member tied to job profitability data. Certification expiry forecasting with crew-composition optimization. Cross-domain warehouse fed from time, employee, job, and equipment event streams.
⚖️
Compliance automation Post-GR
Automated review of jurisdiction-specific labor rules against actual time data. Certified payroll exception detection before submission. Multi-state crew movement compliance alerting.
